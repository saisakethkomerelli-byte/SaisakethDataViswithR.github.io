Summary of Exercise:
The goal of this exercise was to have two different interactive plots in the same data visualisation to have complementing views about the Human Rights Index dataset. So I decided to plot a choropleth and a line graph in the same data visualisation. I changed up my line graph so it would be different from the one I did in a previous exercise and I did this by changing the range of the data that I used. I wasn't sure how to lay out the plots exactly where I wanted them so it ended up just being one plot being printed out directly below the other.
